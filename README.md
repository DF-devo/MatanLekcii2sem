Как пользоваться:
1. Установите Obsidian (https://obsidian.md)
2. Склонируйте репозиторий: `git clone https://github.com/DF-devo/MatanLekcii2sem.git`
3. Откройте папку как хранилище в Obsidian

## Структура хранилища

- `Матанализ/` — заметки с лекциями.
    
- Для каждой теоремы или определения внизу заметки есть ссылки на **развёрнутые версии**:
    
    - `[[РО. ...]]` — развёрнутое определение
        
    - `[[РТ. ...]]` — развёрнутая теорема

Если вы заметили ошибку или чего-то не хватает — напишите мне: @yadfdf

Для удобства есть отдельная заметка с расшифровкой математических знаков: [[Словарь математических символов]]
