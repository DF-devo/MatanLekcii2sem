
## Кванторы и логика

| Символ | Читается | Пример |
|--------|----------|--------|
| ∃ | существует | `∃c ∈ M` — существует c из M |
| ∀ | для любого, для всех | `∀ε>0` — для любого эпсилон больше нуля |
| ⇒ | следует, тогда | `x=y ⇒ ρ(x,y)=0` |
| ⇔ | равносильно, тогда и только тогда | `x=y ⇔ ρ(x,y)=0` |
| → | стремится к | `x_k → a` — последовательность стремится к a |
| ⟹ | следовательно (длинная стрелка) | то же, что ⇒ |
| ⟺ | равносильно (длинная) | то же, что ⇔ |
| ¬ | не | `¬(x=y)` — неверно, что x=y |
| ∧ | и | `(x>0) ∧ (y>0)` |
| ∨ | или | `(x=0) ∨ (y=0)` |

## Операторы и символы множеств

| Символ | Читается                        | Пример            |
| ------ | ------------------------------- | ----------------- |
| ∑      | сумма                           | $∑_{i=1}^n a_i$   |
| ∏      | произведение                    | $∏_{i=1}^n x_i$   |
| ∫      | интеграл                        | $∫_a^b f(x)dx$    |
| ∬      | двойной интеграл                | по площади        |
| ∭      | тройной интеграл                | по объёму         |
| ∂      | частная производная / граница   | $∂f/∂x$, $∂Ω$     |
| ∇      | набла (градиент)                | $∇f = (f_x, f_y)$ |
| ∈      | принадлежит                     | $x ∈ ℝ$           |
| ∉      | не принадлежит                  | $0 ∉ ℕ$           |
| ⊂      | подмножество                    | $ℚ ⊂ ℝ$           |
| ⊆      | подмножество (возможно, равное) |                   |
| ∪      | объединение                     | `A ∪ B`           |
| ∩      | пересечение                     | `A ∩ B`           |
| ∅      | пустое множество                | `A ∩ B = ∅`       |
| ∞      | бесконечность                   | `x → ∞`           |
| ⊥      | перпендикулярно                 |                   |
| ∥      | параллельно                     |                   |

## Сравнения и стрелки

| Символ | Читается | Пример |
|--------|----------|--------|
| ≤ | меньше или равно | |
| ≥ | больше или равно | |
| ≠ | не равно | |
| ∼ | эквивалентно, тильда | `f ∼ g` |
| ≈ | приблизительно равно | `π ≈ 3.14` |
| ≔ | равно по определению | `A ≔ B` |
| ≕ | обозначим | `B ≕ A` |

## Производные и дифференциалы

| Обозначение | Читается                        |
| ----------- | ------------------------------- |
| $f'(x)$     | производная функции f в точке x |
| $df$        | дифференциал f                  |
| $d^2f$      | второй дифференциал             |
| $∂f/∂x$     | частная производная f по x      |
| $f_x$       | частная производная f по x      |
| $∇f$        | градиент f                      |

## Последовательности и пределы

| Обозначение         | Читается                                             |
| ------------------- | ---------------------------------------------------- |
| ${x_k}_1^∞$         | последовательность x_k от 1 до бесконечности         |
| $lim_{k→∞} x_k = a$ | предел x_k при k стремящемся к бесконечности равен a |
| $ρ(x_k, a) → 0$     | расстояние от x_k до a стремится к нулю              |
| $∀ε>0 ∃N$           | для любого эпсилон больше нуля существует номер N    |
| $x_k → a$           | x_k сходится к a                                     |
## Специальные множества
| Обозначение | Читается                           |
| ----------- | ---------------------------------- |
| ℕ           | натуральные числа (1,2,3,…)        |
| ℤ           | целые числа                        |
| ℚ           | рациональные числа                 |
| ℝ           | вещественные числа                 |
| ℂ           | комплексные числа                  |
| ℝⁿ          | n-мерное вещественное пространство 

## Сокращения в тексте лекций

| Сокращение | Расшифровка                                     |
| ---------- | ----------------------------------------------- |
| `ρ(x,y)`   | метрика (расстояние между x и y)                |
| `d(x,y)`   | то же, что ρ (евклидово расстояние)             |
| `м.п.`     | метрическое пространство                        |
| `в.п.`     | векторное пространство                          |
| `ф.н.п.`   | функция нескольких переменных                   |
| `в-ф`      | вектор-функция                                  |
| `Р.О.`     | развёрнутое определение (ссылка на другой файл) |
| `Р.Т.`     | развёрнутая теорема                             |
